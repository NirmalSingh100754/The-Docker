Docker packages the app and all its required dependencies into one container. This container can be moved to any system and it should run the same way everywhere.
command to see if the docker is running :- docker info
containers :- containers are the way to share our application with its dependencies basically replecating entire local development environment.
properties of container:-
1> Portable
2> Light Weight
Docker Image:- Blueprint helps us create multiple containers.
system resources are used by containers not by the image the relation between image and container is similar to relation between class and its object.
